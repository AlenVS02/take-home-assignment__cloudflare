Case 6: Redirection based on user agent

Customer ticket

“I want to redirect visitor with specific user agent (*MSIE 8.0* for example) to a different page. It seems this is not possible with Cloudflare Page Rules. Is there any other way to achieve that using Cloudflare?”

Response to the customer

Hello, dear [customer's name].

Thank you for reaching out with your question regarding user agent-based redirection. You are right that Cloudflare Page Rules do not support redirection based on user agents directly. They only match on the URL, not on request headers like the User-Agent, and are being replaced by newer Cloudflare features such as Transform Rules and Workers, which provide more flexibility for handling requests based on headers and other criteria.

You can implement it without any code by using a Redirect Rule, which is available to all plans.

To set it up, please refer to the following steps:

  1. Go to the Cloudflare dashboard for your domain and navigate to the "Rules" section.
  2. Select "Redirect Rules" and create a new rule.
  3. Set the condition to match the User-Agent header containing the specific value you want to redirect (e.g., *MSIE 8.0*) under Custom filter expression > Edit expression.
  4. Under The "Then" section, specify the destination URL where you want to redirect the matching visitors.
  5. Save and deploy the rule.

By following these steps, you can create a redirection rule that targets visitors with specific user agents without writing custom code. This approach leverages Cloudflare's built-in capabilities to handle header-based conditions efficiently.

To test this redirection, you can use a browser with the specific user agent or a tool like curl to simulate a request with the desired User-Agent header. For example: 

curl -A "Mozilla/4.0 (compatible; MSIE 8.0; Windows NT 6.0)" -I https://example.com/

If you were to need help with logic, such as several conditions or a different page per browser version, you would likely need to use Cloudflare Workers, which allow you to write custom JavaScript to handle requests and implement complex redirection logic based on headers, cookies, or other request attributes.

Please note that OS versions such as Windows XP's Internet Explorer do not support SNI, which our SSL certificates rely on for secure connections. As a result, users on these older systems may encounter SSL errors when trying to access your site.

If your question was not fully addressed by the information provided above, please feel free to reach out with additional details or clarifications so that we can assist you further.

Tools I would use and why

I would primarily use Cloudflare's Page Rules and Workers for this task. Page Rules provide a straightforward way to implement redirection based on URL patterns and conditions, making it suitable for simple user-agent based redirects. For more complex scenarios, such as multiple conditions or dynamic redirection logic, Cloudflare Workers allow for custom JavaScript to handle requests, giving full control over the redirection process based on headers, cookies, or other request attributes.
